# 热血传奇 Go 重制版 — 开发计划

> 基于 `asset/delphi/` 源码（commit 98711da）与 Go 实现的逐行对照。

## 当前状态

端到端登录流程可跑通：登录→选服→门动画→选角（含创建/删除）→公告→进游戏。
P0 基础正确性修复已完成。下一步：Phase 6（角色可动）。

## P0：基础正确性修复 ✅ 已完成

### internal/wil — WIL 图像加载器

- [x] **btVersion/VerFlag 逻辑修正**（标准格式路径）
  - 修正为：VerFlag=0 → btVersion=1 + Seek(-4)；VerFlag≠0 → btVersion=0
  - ILib 格式路径（所有实际资源）逻辑正确，未改动

- [x] **行对齐** — 不适用
  - 经验证：ILib 格式无行填充。Delphi 的 WidthBytes 仅在 LoadDxImage（DirectDraw surface）路径使用，LoadBmpImage/DIB 路径同样读 w*h。Go 代码行为正确。

- [x] **WIX 索引头大小修正**（标准格式路径）
  - 标准格式标题读取改为 41 字节（5 magic + 36 = Delphi String[40]）
  - loadWix 新增 btVersion 参数，VerFlag 处理基于 btVersion 而非猜测
  - ILib 格式路径（所有实际资源）未改动

### internal/protocol — 协议层

- [x] **TAbility 结构体修正**
  - WearWeight/MaxWearWeight/HandWeight/MaxHandWeight 从 uint8 改为 uint16（50字节对齐 Delphi）

- [ ] **TStdItem Name 字段**（暂不修复）
  - Delphi String[20] = 21 字节，Go [20]byte = 20 字节
  - 仅影响与原版客户端互通；Go 客户端+服务端内部一致，不阻塞开发

### internal/mapformat — 地图解析器

- [x] **碰撞检测修正**
  - IsCollision 同时检查 BkImg 和 FrImg 的 bit15

- [x] **门系统实现**
  - 新增：CanMove / CanFly / GetDoor / IsDoorOpen / OpenDoor / CloseDoor
  - CanMove 检查地形碰撞 + 门状态（门关闭时不可通行）

## Phase 6：角色可动 + 基础外观（里程碑：能看到自己和其他玩家走路）

### 已知缺陷（对照 Delphi）

**客户端角色动画系统**：

- [ ] **动画循环行为错误** (`actor_base.go:92-109` vs `Actor.pas:2482-2615`)
  - Go: 所有动画到达 EndFrame 后循环回 StartFrame
  - Delphi: 只有 Stand 循环；攻击/受击/死亡/施法播放一次后停止，回到 DefaultMotion

- [ ] **角色消息队列系统完全缺失** (`Actor.pas:720, 1282-1705`)
  - 缺少：m_MsgList、SendMsg、GetMessage、ProcMsg、ReadyAction、ProcHurryMsg
  - 影响：角色无法响应服务端动作消息

- [ ] **平滑移动插值缺失** (`Actor.pas:1762-1867`)
  - ShiftX/ShiftY 字段存在但从未计算
  - 缺少：Shift(dir, step, cur, max)、Move()、m_dwSmoothMoveTime

- [ ] **深度排序架构错误** (`scene_play.go` vs `PlayScn.pas:1124-1249`)
  - Delphi: 前景物体和角色按 Y 坐标交替渲染
  - Go: 前景层一次性画完，角色未集成到渲染流程

- [ ] **相机不跟随玩家** — 相机固定在地图中心

- [ ] **多层角色渲染缺失** (`Actor.pas:3744-3937`)
  - Delphi 渲染 7 层：翅膀后→武器后→身体→头发→武器前→翅膀前→特效
  - Go 只渲染身体（HairSurface/WeaponSurface 字段存在但从未加载/渲染）

**服务端**：

- [ ] **移动广播未实现** (`playobject.go:71,84` 有 TODO)
- [ ] **视野管理未实现** — GetRangeObjects 存在但从未调用
- [ ] **CanWalk 不检查实体阻挡** — 只检查地形 Flag
- [ ] **门状态不影响碰撞** — ProcessDoors 不修改格子碰撞标志
- [ ] **HandleRun 双步验证缺陷** — 第二步失败时静默停留
- [ ] **BaseObject.Feature() 编码错误** — 传入 Gender 作为 dress

## 设计原则

1. **6Bit 编码保真** — 精确复刻 Delphi 算法，不重新设计
2. **单端口统一监听** — 内部路由登录/选角/游戏消息
3. **单线程游戏循环** — 10 tick/s，避免并发修改游戏状态
4. **每连接双协程** — read loop + write loop，channel 传递消息
5. **自建客户端渲染** — OpenGL 3.3，不使用 ImGui（查看器工具除外）
6. **组件化优于继承** — Go 组合模式替代 Delphi 深度继承链
