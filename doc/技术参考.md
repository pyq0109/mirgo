## 二、WIL/WIX 文件格式

### 2.1 格式概述

WIL 文件是热血传奇的图像资源容器，存储像素数据的有序集合。WIX 是对应的索引文件，记录每个图像在 WIL 中的绝对偏移。

### 2.2 两种容器格式

**ILib 格式**（所有游戏客户端资源均为此格式）：

| 偏移 | 大小 | 字段 | 说明 |
|------|------|------|------|
| 0-39 | 40 | Title | `#ILIB v1.0-WEMADE Entertainment inc.` |
| 40-43 | 4 | VerFlag | 版本标志（!=0 → 8字节图像头，==0 → 12字节） |
| 44-47 | 4 | ImageCount | 图像总数 |
| 48-51 | 4 | ColorCount | 颜色数（256=8-bit，65536=16-bit） |
| 52-55 | 4 | PaletteSize | 调色板大小（通常1024=256×4） |
| 56+ | 1024 | Palette | 256色 BGRA 调色板（仅8-bit模式） |

WIX 索引文件（`#INDX` 签名）：

| 偏移 | 大小 | 字段 | 说明 |
|------|------|------|------|
| 0-39 | 40 | Title | `#INDX v1.0-WEMADE Entertainment inc.` |
| 40-43 | 4 | Unknown | 未知字段 |
| 44-47 | 4 | IndexCount | 索引数量（与 WIL ImageCount 一致） |
| 48+ | 4×N | Offsets | 每个图像在 WIL 文件中的绝对偏移（int32） |

**标准格式**（旧版，当前资源中未见）：

Delphi 中 `TWMImageHeader` 使用 `String[40]`（41字节）：
- Title(41) + ImageCount(4) + ColorCount(4) + PaletteSize(4) + VerFlag(4)
- VerFlag=0 → 旧格式（无 VerFlag 字段，那 4 字节是调色板起始）→ btVersion=1，Seek(-4)
- VerFlag≠0 → 新格式（12字节图像头）→ btVersion=0

### 2.3 图像头

| 偏移 | 大小 | 字段 | 说明 |
|------|------|------|------|
| 0-1 | 2 | Width | int16 |
| 2-3 | 2 | Height | int16 |
| 4-5 | 2 | HotX | 热点X (int16) |
| 6-7 | 2 | HotY | 热点Y (int16) |
| 8-11 | 4 | Bits | 仅 btVersion=0 时存在（通常为0） |

### 2.4 像素数据

- **8-bit 调色板**（ColorCount ≤ 256）：每像素 1 字节索引，查 Palette 得 RGBA。Palette[0] = 透明。
- **16-bit RGB565**（ColorCount > 256）：每像素 2 字节，0x0000 = 透明。

```
R = (pixel >> 11) << 3
G = ((pixel >> 5) & 0x3F) << 2
B = (pixel & 0x1F) << 3
```

### 2.5 扫描线方向

WIL 文件存储像素采用**底到顶**扫描线顺序（与 BMP 相同）。`internal/wil/wil.go` 加载后执行行翻转为顶到底。

### 2.6 WIX 文件名兼容

部分 WIX 文件名存在异常（如 `Deco..wix` 对应 `Deco.wil`），加载器在标准路径找不到时遍历同目录 `*.wix` 按 base name 匹配。

### 2.7 WIL 文件分类

**动画文件**（11类）：Hum, HumEffect, Hair, Weapon, Mon1~18, Npc, Magic, Magic2, Effect, Event, Dragon

**静态文件**（11类）：Items, StateItem, DnItems, Prguse, Prguse2, Prguse3, ChrSel, mmap, Tiles, SmTiles, MagIcon

**混合文件**（1类）：Objects~ObjectsN（通过地图 btAniFrame 字段区分）

## 三、地图文件格式

### 3.1 文件头（52字节）

```
TMapHeader:
  wWidth      : Word        — 地图宽度(格子数)
  wHeight     : Word        — 地图高度(格子数)
  sTitle[16]  : String      — 地图标题
  UpdateDate  : TDateTime   — 更新日期(8字节)
  Reserved[22]: Char        — 保留
```

### 3.2 每格数据（12字节）

```
TMapInfo:
  wBkImg       : Word   — 背景图索引(bit15=碰撞, bits0-14=1-based索引)
  wMidImg      : Word   — 中间层图索引
  wFrImg       : Word   — 前景层图索引(bit15=碰撞)
  btDoorIndex  : Byte   — 门索引(bit7=有门, bits6-0=门组ID)
  btDoorOffset : Byte   — 门偏移(bit7=门开启, bits6-0=偏移量)
  btAniFrame   : Byte   — 动画帧数(bit7=Alpha混合, bits6-0=帧数)
  btAniTick    : Byte   — 动画间隔
  btArea       : Byte   — 区域标识(选择 Objects{N+1}.wil)
  btLight      : Byte   — 光照等级(0~4)
```

### 3.3 存储方式

**列优先**存储（先存第1列所有行，再存第2列...），解析后转行优先。

### 3.4 碰撞检测（Delphi MapUnit.pas:320）

```pascal
Result := ((wBkImg and $8000) + (wFrImg and $8000)) = 0;
// 还需检查门：btDoorIndex bit7=有门 且 btDoorOffset bit7=0(关闭) → 不可通行
```

### 3.5 门系统（Delphi MapUnit.pas:346-405）

- `GetDoor(x,y)` — 返回门组 ID（btDoorIndex & 0x7F），无门返回 0
- `IsDoorOpen(x,y)` — btDoorOffset & 0x80 != 0
- `OpenDoor(x,y)` — 对同门组所有格子设置 btDoorOffset |= 0x80
- `CloseDoor(x,y)` — 对同门组所有格子清除 btDoorOffset &= 0x7F

## 四、动画系统

### 4.1 TActionInfo 结构（Actor.pas:35）

```pascal
TActionInfo = packed record
  start   : Word;  // 起始帧索引
  frame   : Word;  // 实际动画帧数
  skip    : Word;  // 每方向填充帧数
  ftime   : Word;  // 每帧显示时间(ms)
  usetick : Word;  // 速度控制(走/跑)
end;
```

**帧索引计算公式**：
```
实际帧 = start + direction × (frame + skip) + 当前帧偏移
结束帧 = start + direction × (frame + skip) + frame - 1
```

### 4.6 NPC 动画

固定使用 Npc.wil，每种 NPC 占 60 帧（MERCHANTFRAME）。只有 3 个方向。

### 4.7 地图物体动画（Objects.wil）

- `btAniFrame = 0` → 静态

- 帧计算：`frame = (animCounter % (ani + ani*tick)) / (1+tick)`
- `btArea` → 选择 Objects{N+1}.wil

## 五、渲染管线

### 5.1 地图三层渲染

| 层 | 数据字段 | 资源文件 | 渲染方式 |
|---|---|---|---|
| 背景层 | wBkImg | Tiles.wil | stride-2（偶数x,y），覆盖2×2格子 |
| 中间层 | wMidImg | SmTiles.wil | 逐格渲染 |
| 前景层 | wFrImg | Objects*.wil | 逐格，动画+blend |

**Delphi 完整渲染顺序**（PlayScn.pas PlayScene 方法）：
1. 背景层 + 中间层 → MapSurface
2. 前景小物体 + 角色 + 地面物品 **按 Y 坐标交替渲染**（深度排序）
3. 前景大物体
4. 光照/迷雾叠加（lig0a~f.dat，6级光罩）
5. 小地图

### 5.2 Blend 混合（火焰/灯光）

- 检测：`AniFrame & 0x80 != 0`
- 渲染：`glBlendFunc(SRC_ALPHA, ONE)`（加法混合）
- 定位：热点偏移 `x = cellX*48 + hotX - 2, y = cellY*32 + hotY - 68`

### 5.3 Door Offset 渲染

- `FrontDoorOffset & 0x80` — 门是否开启
- 开启时：`imageIdx += (FrontDoorOffset & 0x7F)`

### 5.4 OpenGL 纹理上传

WIL 行翻转后（顶到底），通过 `glTexImage2D` 上传。第一行（顶行）位于纹理 V=0（底部）。在 Y-down 正交投影下方向正确。

### 5.5 正交投影

**OrthoProj（Y-down）**：客户端使用，Y=0 是屏幕顶部。

**OrthoProj4（通用）**：mapviewer 和 scene_play 使用，支持相机平移。

### 5.6 光照系统（Delphi PlayScn.pas:28-129, 603-787）

- 6 级预计算光罩 LightMask0~5（3×3 到 17×17）
- 从 `Data/lig0a~f.dat` 加载
- `SM_DAYCHANGING` 驱动昼夜：`g_nDayBright` 控制全局亮度，`DarkLevel>0` 启用迷雾
- `ApplyLightMap` 逐格叠加光照

### 5.7 文字渲染

`internal/engine/text.go` 使用 `golang.org/x/image/font/opentype` 光栅化 TTF 字形，按需缓存为 GL 纹理。

## 九、通信协议详解

### 9.1 6Bit 编解码算法

源码：`Common/EDcode.pas`。OLDMODE（无 XOR 混淆），每 3 字节 → 4 字符，偏移 `$3C`。

**编码**（Encode6BitBuf）：
- 每字节从 bit 2 开始取 6 位，加 `$3C` 输出为可打印 ASCII
- `nRestCount` 在 0→2→4 间循环，到 6 时同时输出 btMade + btRest 并重置
- 输出字符范围：`$3C`(`<`) ~ `$7B`(`{`)

**解码**（Decode6BitBuf）：
- 每字符减 `$3C` 恢复 6-bit 值
- `nBitPos` 在 2→4→6 间循环，掩码 `$FC/$F8/$F0/$E0/$C0`
- 累积 ≥8 位时重建完整字节

**高层封装**：
| 函数 | 说明 |
|------|------|
| EncodeMessage/DecodeMessage | TDefaultMessage(12B) ↔ 16字符 |
| EncodeString/DecodeString | 字符串 ↔ 6Bit |
| EncodeBuffer/DecodeBuffer | 二进制 ↔ 6Bit |

编码后长度：`ceil(n * 4 / 3)`。TDefaultMessage(12B) → 16字符（DEFBLOCKSIZE）。

### 9.2 消息帧格式

**客户端 → 服务器**：`#<1位序列号><载荷>!`
- 序列号 1-9 循环递增（ClMain.pas SendSocket）
- 载荷模式：
  - 仅 EncodeMessage(msg) — 简单消息
  - EncodeMessage(msg) + EncodeString(text) — 携带文本
  - EncodeMessage(msg) + EncodeBuffer(buf) — 携带二进制
  - 仅 EncodeString(text) — RunLogin 等特殊消息

**服务器 → 客户端**：`#<载荷>!`（无序列号）

**控制消息前缀**（不经过 6Bit 编码，纯 ASCII）：
- `+GOOD` — 动作确认（ActionLock := FALSE）
- `+FAIL` — 动作失败
- `+PWR/+LNG/+ULNG/+WID/+UWID/+CRS/+UCRS/+TWN/+UTWN/+FIR/+UFIR` — 技能开关
- `=DIG` — 挖掘标志

### 9.3 TDefaultMessage 字段用途约定

| 字段 | 通用用途 |
|------|------|
| Recog (4B) | 认证码/对象ID/数值结果 |
| Ident (2B) | 消息 ID |
| Param (2B) | X 坐标或子命令 |
| Tag (2B) | Y 坐标或附加参数 |
| Series (2B) | 方向或序列号 |

### 9.4 完整登录时序

```
客户端                              LoginGate:7000
  |--- TCP 连接 ----------------------->|
  |--- #1<CM_IDPASSWORD + 凭据>! ----->|  body="账号/密码"
  |<-- #<SM_PASSOK_SELECTSERVER> ------|  body="服务器名/状态"
  |--- #2<CM_SELECTSERVER + 名称>! --->|
  |<-- #<SM_SELECTSERVER_OK> ---------|  body="addr/port/cert"
  |--- TCP 断开 ------------------------|

客户端                              SelGate:7100
  |--- TCP 连接 ----------------------->|  → 门动画
  |--- #1<CM_QUERYCHR + id/cert>! --->|
  |<-- #<SM_QUERYCHR> ----------------|  body="*name/job/hair/level/sex/..."
  |--- #2<CM_SELCHR + id/name>! ----->|
  |<-- #<SM_STARTPLAY> ---------------|  body="addr/port"
  |--- TCP 断开 ------------------------|

客户端                              RunGate:7200+
  |--- TCP 连接 ----------------------->|
  |--- #1<EncodeString("**id/name/cert/ver/9")>! -->|
  |<-- #<SM_SENDNOTICE> --------------|
  |--- #2<CM_LOGINNOTICEOK>! -------->|
  |<-- #<SM_NEWMAP> ------------------|
  |<-- #<SM_LOGON> -------------------|  → 切换到 stPlayGame
  |<-- #<SM_ABILITY/SM_SENDUSEITEMS/SM_BAGITEMS/SM_SENDMYMAGIC/...>
```

### 9.5 RunGate ↔ M2Server 二进制协议

帧头 TMsgHeader（16字节）：
```
dwCode:DWord($AA55AA55) + nSocket:Integer + wGSocketIdx:Word +
wIdent:Word(GM_*) + wUserListIndex:Word + nLength:Integer
```

GM_* 类型：GM_OPEN(1), GM_CLOSE(2), GM_CHECKSERVER(3), GM_CHECKCLIENT(4), GM_DATA(5), GM_SERVERUSERINDEX(6), GM_RECEIVE_OK(7)

nLength 语义：>0 = TDefaultMessage + 可选消息体；<0 = 纯文本；=0 = 无载荷

### 9.6 流控与心跳

- **客户端 ↔ Gate**：Gate 发送 `*` 字符请求确认，客户端回复 `*`。超时 3 秒暂停发送。
- **RunGate ↔ M2Server**：GM_CHECKCLIENT/GM_CHECKSERVER 每 2 秒，超时 3 分钟断开。
- **LoginGate ↔ LoginSrv**：`%--$` / `%++$` 每 2 秒，超时 10 秒。
- **SM_TIMECHECK_MSG(810)**：服务器时间戳，客户端检测速度作弊。

### 9.7 进程间文本协议

| 链路 | 帧格式 | 示例 |
|------|------|------|
| LoginGate ↔ LoginSrv | `%...$` | `%O<socket>/<用户IP>/<网关IP>$` |
| SelGate ↔ DBServer | `%...$` | 同上 |
| M2Server ↔ LoginSrv | `(...)` | `(SS_SERVERINFO/<名称>/<索引>/<人数>)` |
| M2Server ↔ DBServer | `#...!` + 校验和 | `#<id>/<编码消息><校验>!` |

### 9.8 Go 实现与 Delphi 差异

| 方面 | Delphi | Go |
|------|--------|-----|
| 架构 | 8 进程分布式 | 单进程单端口 |
| 重连 | 断开→连 SelGate→断开→连 RunGate | 断开→重连同一服务器+重新认证 |
| 认证 | LoginGate→LoginSrv | 直接验证 SQLite |
| 角色查询 | SelGate→DBServer | 直接查询 SQLite |
| 输入过滤 | `~`/`'`→`_`, 账号 LowerCase | 已实现 `~`/`'`→`_` |
